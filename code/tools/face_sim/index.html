Drawing reference 
c  = the canvas. Same calls as MonochromeCanvas in code/src/watch_ui.cpp:
  c.clear(black=false)
  c.pixel(x, y, black=true)
  c.line(x0, y0, x1, y1, black=true)
  c.rect(x, y, w, h, black=true)          outline
  c.fillRect(x, y, w, h, black=true)
  c.circle(cx, cy, r, black=true)         outline
  c.fontTextWidth(font, text)
  c.fontText(font, text, x, y, black=true)            y = top of the line
  c.centeredFontText(font, text, cx, y, black=true)
  c.centeredFittedFontText(font, text, cx, y, maxWidth, black=true)   cut with "..."
  c.icon(Icon.Name, cx, cy, size, black=true)         size 16 or 28
  c.progress(x, y, w, percent, h=10)      WatchUi::drawProgress
  c.toggle(x, y, on)                      WatchUi::drawToggle

Simulator only (the firmware has no equivalent yet):
  c.fillCircle(cx, cy, r, black=true)
  c.ttfText(text, x, y, px, {bold: true, center: false, black: true})
  c.ttfWidth(text, px, {bold: true})
      Renders the Atkinson Hyperlegible Next TTF at any size and thresholds it
      to 1 bit, to try a size before adding it to generate_ui_assets.py. The
      browser's rasteriser is not identical to the generator's, so expect
      one-pixel differences.

F  = fonts: F.Ui16 (regular 16), F.Bold22, F.Bold36, F.Clock64 (extra bold).
     Each has .size, .ascent, .descent. ASCII 32..126 only; anything else draws "?".
Icon = Notifications, Timer, Alarms, Music, Weather, Sensors, Activity,
       Settings, Bluetooth, Battery.
m  = the watch state, with the field names of WatchUiModel (include/watch_ui.h).
